browser-linux idle

a computer you can borrow

Press Start to boot a small Linux inside this tab.

Nothing downloads until you do, and nothing you do here leaves this browser.

Give it a minute: the guest starts from firmware like a real machine, so the screen stays blank for a while before anything appears. The text-shell image is up far sooner if you just want a prompt.

Prototype: reloading throws the machine away. Keeping what you changed is the next milestone, and the hard one.
